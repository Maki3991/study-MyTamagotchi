# React 页面切换与组件数据流｜学习计划

## 学习目标

用这一个项目，先看懂 React 页面切换的基本骨架：

`main.tsx` 启动应用 → `App` 保存当前界面状态 → 顶部组件报告用户点击 → 状态改变 → `renderSection()` 选择要显示的页面组件。

完成第一课后，你不需要会写 React 代码，但应该能用自己的话回答：

- 程序从哪个文件开始显示界面？
- 当前正在看哪个页面的信息保存在哪里？
- 用户点击顶部导航后，谁接收这个点击？
- 状态改变后，谁决定显示哪个页面？

## 已知基础与本课边界

已经确认：

- 你能运行这个 mobile 前端，并已经大致理解 `backendApi.ts` 是对后端请求的封装。
- 你的目标是理解项目的文件职责、组件关系和数据流，而不是把每一行代码背下来。

本课暂时不学习：

- 后端、数据库和 API 请求；
- CSS 和 UI 基础组件；
- React Hook 的实现细节；
- 如何从零编写这些组件。

## 学习路径

1. 看 `main.tsx`：找到应用启动入口。
2. 看 `App.tsx`：只识别与页面切换有关的几个 State。
3. 看 `HomeTopTabs`：理解 Props 和点击回调。
4. 看 `navigate()`：理解项目如何用状态模拟页面跳转。
5. 看 `renderSection()`：理解状态如何决定最终显示哪个 Screen。
6. 用“选择 Vitality Gym”这条路径复述一次完整数据流。
