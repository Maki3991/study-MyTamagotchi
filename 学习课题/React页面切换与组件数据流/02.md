# 02｜先别学 React：程序怎样决定现在显示哪一页？

## 这一篇要解决的问题

你刚才的反馈说明，上一课一次放进了太多抽象角色。现在我们把范围缩到一个动作：你点击顶部的 `Plaza`，为什么画面会变成广场？

这一篇暂时不要求你理解 `State`、`Props`、回调函数这些词。我们先看“页面为什么会变”，最后再给这些东西贴上代码里的名字。

> 本篇根据你刚才的实际反馈调整：你不需要先找出自己哪里不懂，只要跟着一个真实操作走；每次只回答一个很小的问题。

## 1. 先只看你在屏幕上做了什么

你现在打开的网页，可以想成一个“内容窗口”。顶部有几个按钮：

```text
Scene   Agents   Plaza   链上广场
```

你点击 `Plaza` 后，顶部按钮的颜色变了，下面的内容也变成了 Public Plaza。

程序至少要记住一件事：

```text
当前顶部栏目 = Plaza
```

只要程序记住了这个结果，它就能按照规则显示广场内容。

这张“当前栏目标签”，在代码里叫 `homeView`。你可以先把它理解成一张贴在程序内部的小纸条：纸条上写着 `scene`、`civilization`、`plaza` 或 `chainPlaza` 其中一个值。

## 2. 先看“点击按钮之后写什么”

打开：

`frontends/mobile/src/app/App.tsx:6551`

然后向下看 35 行左右。你会看到三个顶部按钮分别有这样的动作：

| 你点击的按钮 | 程序把“当前栏目标签”改成什么 |
| ------------ | ---------------------------- |
| Agents       | `civilization`               |
| Plaza        | `plaza`                      |
| 链上广场     | `chainPlaza`                 |

你现在只看 `Plaza` 那一行：`App.tsx:6568`。

它表达的意思可以翻译成一句普通话：

```text
当用户点击 Plaza，就把当前栏目标签改成 plaza。
```

这里先不要管 `onViewChange` 这个词。你只要看到：这一行负责接收点击，并把“当前栏目”改成 `plaza`。

## 3. 再看“标签写成 plaza 后显示什么”

打开：

`frontends/mobile/src/app/App.tsx:6866`

向下看。你会看到几条条件：

| 代码里的条件                                        | 画面中显示的内容                   |
| --------------------------------------------------- | ---------------------------------- |
| `homeView === "civilization"`                       | Agents 页面                        |
| `homeView === "plaza"`                              | `PlazaScreen`，也就是 Public Plaza |
| `homeView === "chainPlaza"`                         | 链上广场页面                       |
| `homeView === "scene"` 且 `homeSub === "worldDock"` | 三个世界的总览页                   |
| `homeView === "scene"` 且 `homeSub === "everyday"`  | Vitality Gym                       |

把 `homeView === "plaza"` 这一行翻译成普通话就是：

```text
如果当前栏目标签写的是 plaza，就显示 PlazaScreen。
```

因此，点击 Plaza 的完整过程只有两步：

```text
点击 Plaza
    ↓
当前栏目标签改成 plaza
    ↓
程序发现标签是 plaza，于是显示 Public Plaza
```

## 4. 现在才给两个东西起代码名字

你刚才看到的两个动作，在代码里分别有名字：

- “当前栏目标签”叫 `homeView`，这类会影响画面的记忆叫 State；
- “根据标签选择画面”发生在 `renderSection()` 里。

所以这一篇只需要暂时记住：

```text
homeView = 程序记住当前栏目
renderSection() = 程序根据当前栏目选择画面
```

这已经足够解释 `Scene`、`Agents`、`Plaza` 之间的切换。`App`、`Props`、`navigate()` 等其他词，先不一起学习。

## 5. 这一篇只看两个位置

请暂时不要打开 `main.tsx`，也不要阅读 `App.tsx` 的 7000 多行。只看：

1. `App.tsx:6568`：点击 Plaza 后发生什么；
2. `App.tsx:6868`：`homeView` 是 `plaza` 时显示什么。

如果你能看懂这两行，第一层就完成了：你知道“用户操作”如何变成“页面选择”。

## 小结

- 网页点击顶部按钮后，程序会记录当前选择的栏目。
- `Plaza` 点击对应的栏目值是 `plaza`。
- `renderSection()` 根据这个值选择 `PlazaScreen`。
- 目前只需要把 `homeView` 理解成“当前栏目标签”。
