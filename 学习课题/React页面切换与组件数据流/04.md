# 04｜把一条 React 语法翻译成实际动作

## 这一篇要解决的问题

你已经理解了整个流程，现在只卡在代码的具体写法。本篇只追踪点击 Plaza 的一条链，解释 onClick={() => ...} 和 onViewChange={setHomeView} 每一部分做什么。

本篇不讲新的页面、不讲后端，也不要求你写代码。

## 1. 先看完整的两行代码

点击 Plaza 的源码在 App.tsx:6568：

    onClick={() => onViewChange("plaza")}

App 把函数传给顶部导航组件的源码在 App.tsx:6861：

    onViewChange={setHomeView}

这两行合在一起的作用是：

    用户点击 Plaza
    → 调用 setHomeView("plaza")

下面逐段翻译它们的语法。

## 2. onClick={...}：告诉 React 点击时执行什么

在 React 的组件写法里，onClick 表示“点击事件对应的处理函数”。

    onClick={某个函数}

意思是：把“某个函数”交给 React；用户点击时，React 调用它。

花括号 {} 表示这里放的是 JavaScript 表达式。它让这段组件标记可以使用 JavaScript 的变量和函数。

因此：

    onClick={() => onViewChange("plaza")}

可以先读成：

    点击发生时，执行右边这段函数。

## 3. () => ...：创建一个暂时不执行的函数

    () => onViewChange("plaza")

这是箭头函数。当前只需要看三个部分：

    ()       → 这个函数没有主动使用参数
    =>       → 箭头，表示“这个函数执行下面的内容”
    后面的内容 → 函数真正执行的动作

所以它的实际过程是：

    页面加载时：先准备好这个函数，但不调用
    用户点击时：React 调用这个函数
    函数执行：调用 onViewChange("plaza")

这里的空括号不代表“传入一个空值”。它表示这个箭头函数没有声明要使用的参数。浏览器传来的点击事件被它忽略了。

## 4. onViewChange("plaza")：调用函数并传入值

函数名后面带括号，表示调用函数：

    onViewChange("plaza")

括号里的 "plaza" 是传给函数的参数。

所以这一小段可以逐词翻译：

    调用 onViewChange 这个函数
    并把字符串 "plaza" 传进去

## 5. onViewChange={setHomeView}：把函数交给另一个组件

这一行位于 App 创建 HomeTopTabs 的地方：

    <HomeTopTabs onViewChange={setHomeView} />

它的结构是：

    左边 onViewChange → 交给 HomeTopTabs 的输入名称
    右边 setHomeView → 实际交过去的函数

这行代码的含义是：

    把 App 里的 setHomeView 函数，交给 HomeTopTabs，
    并在 HomeTopTabs 内部把它称为 onViewChange。

因此，在 HomeTopTabs 内部：

    onViewChange("plaza")

实际执行的就是 App 的：

    setHomeView("plaza")

这就是你刚才疑惑的“onViewChange 是否调用了 setHomeView”：答案是，App 把 setHomeView 这个函数交给了 HomeTopTabs，那里使用了另一个名字 onViewChange。

## 6. 最容易混淆的三个写法

### 写法一：只写函数名

    onViewChange={setHomeView}

意思是：把函数交出去，暂时不执行。

### 写法二：函数名后面带括号

    setHomeView("plaza")

意思是：现在立刻调用函数，并传入 "plaza"。

### 写法三：用箭头函数包起来

    onClick={() => setHomeView("plaza")}

意思是：先交给 onClick 一个函数；等点击发生时，再调用 setHomeView("plaza")。

可以用这张表区分：

| 写法                       | 此刻发生什么             |
| -------------------------- | ------------------------ |
| setHomeView                | 得到函数本身，暂时不执行 |
| setHomeView("plaza")       | 立刻执行函数             |
| () => setHomeView("plaza") | 创建一个以后执行的函数   |

## 7. 把完整语法链读一遍

相关代码位置：

- App.tsx:6625：创建 homeView 和 setHomeView；
- App.tsx:6861：把 setHomeView 交给 HomeTopTabs，并命名为 onViewChange；
- App.tsx:6568：点击 Plaza 时调用 onViewChange("plaza")；
- App.tsx:6870：检查 homeView 是否等于 plaza；
- App.tsx:7011：调用 renderSection() 生成当前页面结构。

按时间顺序就是：

    App 创建 setHomeView 函数
    → App 把它作为 onViewChange 交给 HomeTopTabs
    → 用户点击 Plaza
    → 箭头函数执行
    → onViewChange("plaza") 执行
    → 实际调用 setHomeView("plaza")
    → homeView 更新为 "plaza"
    → renderSection() 选择 PlazaScreen

## 8. 关于“6000 多行代码怎么找”

这会贯穿后面的学习。当前可以先掌握一种固定方法：

    从一个具体操作开始
    → 搜索界面文字或 onClick
    → 找到被调用的名字
    → 搜索这个名字在哪里传入
    → 搜索这个名字在哪里定义
    → 找到它如何影响页面

这次的搜索路线就是：

    Plaza
    → onViewChange
    → setHomeView
    → homeView
    → PlazaScreen

你不需要通读 6000 多行。每次只围绕一个操作，沿着变量名和函数名追踪几处关键位置。

## 小结

- onClick={...} 把点击时要执行的函数交给 React。
- () => ... 创建一个稍后执行的箭头函数。
- onViewChange("plaza") 调用函数，并把 "plaza" 传入。
- onViewChange={setHomeView} 把 setHomeView 函数交给另一个组件使用。
- 函数名和函数调用的区别，关键看后面有没有括号。
